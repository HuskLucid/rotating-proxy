How it works

1. Service fetches hundreds of free proxies from the internet
2. Each user gets a different upstream proxy (different exit IP)
3. If User A's exit IP is blocked, Users B, C, D still work
4. Click "Rotate" to change a user's exit IP
5. Pool auto-refreshes every 5 minutes

Format: ip:port:user:pass
